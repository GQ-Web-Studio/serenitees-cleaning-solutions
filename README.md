# Serenitees Cleaning Solutions

A responsive website for Serenitees Cleaning Solutions, promoting residential, Airbnb and short-term rental, and commercial cleaning services across Durham Region, Toronto GTA, and surrounding areas.

**Live preview:** [View the website](https://gq-web-studio.github.io/serenitees-cleaning-solutions/)

## Pages

- Home
- About
- Residential Cleaning
- Commercial Cleaning
- Contact
- Request a Quote
- Privacy Policy

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- WebP media and GLB 3D assets

npm run preview
